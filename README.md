Python project for reading/editing SS14 prototypes, textures and audio.

Requirements:
```
- Python 3.14.2
- Windows 10/11(You can use Linux or Linux-like, but you need to rewrite .bat files a little bit)
```

0. Change directory to the project's root folder
1. To initiate virtual environment via command `gen_env`
2. Download packages `inst_pckgs`
3. You're done

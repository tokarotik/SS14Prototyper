## About
Python project for reading/editing SS14 prototypes, textures and audio.

## Requirements
- Python 3.14.2
- Windows 10/11(
				You can use Linux or 
				Linux-like OS, but you need to rewrite 
				.bat files a little bit
			   )


## Prepare to work
0. Change directory to the project's root folder(youre SS14 server)
1. Initiate the virtual environment run `gen_env`
2. Activate the virtual enviroment `activate`
2. Then download the required packages `inst_pckgs`
3. You're done
